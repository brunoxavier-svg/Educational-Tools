# Standing Wave Simulator

An interactive educational tool for visualizing standing waves
and wave interference using Python.

## 🎯 Objective

This project was developed as an educational resource to help
students understand wave behavior, wavelength, frequency,
reflection, standing-wave formation and how use python to solve problems.

## 🛠️ Technologies

- Python
- NumPy
- Plotly
- Google Colab

## 📚 Physics Concepts

- Wave propagation
- Wavelength
- Frequency
- Wave velocity
- Reflection
- Interference
- Standing waves

## 🚀 How to Use

Enter the wave velocity and string length. The simulator then
allows the user to explore different wavelengths using an
interactive slider.

## 💡 Educational Purpose

The tool is designed to support physics teaching and python by providing
an interactive visualization of concepts that are difficult to
observe directly in a traditional classroom.
